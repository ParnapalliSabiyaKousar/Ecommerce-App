# 🛍️ E-Commerce Web Application

A modern full-stack E-Commerce website inspired by apps like Meesho and Shopsy.

---

## 🚀 Features

✅ User Registration & Login  
✅ JWT Authentication  
✅ Admin & User Roles  
✅ Add/Delete Products (Admin Only)  
✅ Product Categories  
✅ Product Search & Filtering  
✅ Shopping Cart System  
✅ Responsive UI Design  
✅ MongoDB Database  
✅ Secure Backend API  

---

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Authentication
- JWT (JSON Web Token)
